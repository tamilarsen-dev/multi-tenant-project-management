# Multi-Tenant Project Management API

A portfolio project focused on building a realistic multi-tenant project management backend, inspired by Jira and Linear.

The project emphasizes software engineering practices: domain modeling, tenant isolation, authorization, relational data integrity, transactions, concurrency, API design, and implementation planning.

## Technology Stack

- Node.js 24 and TypeScript
- Express 5
- PostgreSQL 18 and Prisma 7
- Zod 4
- Vitest and Supertest
- Pino and pino-http
- Docker Compose
- OpenAPI / Swagger UI
- ESLint and GitHub Actions

## Project Status

The Understand, Specify, and Design stages have been completed. Stage 04 (Plan) defines the Technical Foundation and the implementation roadmap for feature delivery through vertical slices.

## Documentation

Project context, requirements, domain and design decisions, and implementation planning are maintained in [`docs/`](docs/README.md). The documents follow the project's engineering workflow from Understand through Plan.
